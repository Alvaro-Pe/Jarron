Jarron – E-Commerce + Personalización de Camisetas

Jarron es un proyecto tipo e-commerce creado para la Hackathon Fondecor – Desafío Desarrollo Web. Su propósito principal es simular una tienda en línea permitiendo al usuario comprar camisas ya disponibles y también brindar un valor agregado: personalizar sus propias prendas con imágenes y vista previa antes de simular el pago.
Este desarrollo nace como reto y evoluciona incorporando un módulo adicional para administrador, desde donde se pueden agregar nuevas camisetas (productos), subir imágenes, editar información y mantener actualizado el catálogo.

🚀 Características principales

 🛒 Función para el cliente

Visualización de camisetas disponibles para compra.
Opción para personalizar camisas subiendo imágenes.
Vista previa del diseño aplicado en tiempo real.
Carrito de compra funcional.
Flujo de pago simulado con mensaje final de compra exitosa.

 🔐 Área Administrativa (PLUS agregado al proyecto)

Panel para agregar nuevas camisetas al catálogo.
Registro de producto + imagen.
Control básico para administración y carga de datos.(Este componente se desarrolló como plus diferencial, más allá de lo solicitado por el reto.)
